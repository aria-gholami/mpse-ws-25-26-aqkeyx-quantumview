## Über DDEV
DDEV ist eine Docker-basierte lokale Entwicklungsumgebung für PHP-Projekte. Es bietet eine einfache Möglichkeit, konsistente Entwicklungsumgebungen über verschiedene Projekte und Entwickler hinweg zu erstellen.
