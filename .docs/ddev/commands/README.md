## 🚀 Starts/Stoppe Umgebung
Starte Umgebung:
```
ddev start
```
✅ Nach dem Start ist die Vite-App erreichbar unter: https://quantumview.ddev.site:5173/

Beende DDEV:
```
ddev poweroff
```
Stoppe Umgebung:
```
ddev stop
```
Zeige DDEV Umgebungsdetails an:
```
ddev describe
```
