## Was ist Redux Toolkit?
Redux Toolkit (RTK) ist das offizielle, empfohlene Toolset für die effiziente Redux-Entwicklung. Es wurde entwickelt, um drei häufige Probleme mit Redux zu lösen:

- Zu komplexe Store-Konfiguration
- Zu viele Packages für produktiven Redux-Einsatz erforderlich
- Zu viel Boilerplate-Code
