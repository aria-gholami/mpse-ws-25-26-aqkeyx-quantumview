## E-Mail-Template anpassen
Das Template für die Contact-Mail liegt hier:
```
cms/templates/emails/contact.html.twig
```
Dort können u.a. angepasst werden:
- Layout & Styling
- Textinhalte
- Darstellung optionaler Felder (`organization`, `topic`)
- Sprache & Tonalität

Nach Änderungen:
- Erneuter Request
- Änderungen sind sofort in Mailpit sichtbar
